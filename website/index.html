Simple loop

From reminder to confirmation.

1

Set the schedule

The user chooses a compartment, enters a name, and sets one daily time.

2

The box alerts

At the scheduled time, the matching compartment lights up and the device alerts.

3

The lid confirms

When the magnet moves away from the reed switch, the system records the dose.

4

The app updates

Taken and missed doses appear in the history for the user or caregiver.
